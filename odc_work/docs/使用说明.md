## 1. 快速开始

### 启动

```bash
opendracocli                  # 默认启动（TTY 用 Textual TUI，非 TTY 自动降级）
opendracocli --no-startup     # 跳过启动动画
opendracocli --renderer simple    # 强制 prompt_toolkit 简单循环
opendracocli --renderer textual   # 强制 Textual TUI
opendracocli --theme dark         # 指定主题
opendracocli --setup-auth         # 设置 critical 级操作密码
```

启动后提示符形如：

```
draco ~/projects/myapp>
```

`cd` 后提示符会同步更新当前目录。

### 第一次使用

```bash
ls              # 看看当前目录
pwd             # 当前路径
echo hello      # 输出
/help           # 查看内置命令
/quit           # 退出（Ctrl+D 亦可）
```

> **核心特点**：所有基础命令都由 Rust 内核在进程内执行，**不调用** `/bin/sh`、`cmd.exe` 或任何系统 shell，Windows / Linux / macOS 行为完全一致。

## 2. 基础命令（Rust 内核）

16 个高频命令，零 IPC 开销：

| 命令 | 常用用法 | 说明 |
|------|----------|------|
| `ls` | `ls`、`ls -l`、`ls -a`、`ls -h`、`ls *.py` | 列目录，支持多路径与 glob |
| `cd` | `cd sub/dir`、`cd ..` | 切换目录（session 级持久） |
| `pwd` | `pwd` | 当前工作目录 |
| `cat` | `cat a.py`、`cat a.py b.py` | 查看文件内容（可多文件） |
| `head` | `head -n 10 file` | 前 N 行 |
| `tail` | `tail -n 5 file` | 后 N 行 |
| `cp` | `cp -r src dst` | 复制（`-r` 递归） |
| `mv` | `mv old new` | 移动 / 重命名 |
| `rm` | `rm file`、`rm -r dir` | 删除（`-r` 递归） |
| `mkdir` | `mkdir -p a/b/c` | 创建目录（`-p` 递归） |
| `rmdir` | `rmdir emptydir` | 删除空目录 |
| `touch` | `touch newfile` | 创建文件 / 更新时间戳 |
| `stat` | `stat a.py` | 文件元信息 |
| `ln` | `ln -s target link` | 创建符号链接 |
| `echo` | `echo hello`、`echo -n hello` | 输出（`-n` 不换行） |
| `wc` | `echo hi \| wc`、`wc file` | 统计行/词/字节 |

### ls 的进阶用法

```bash
ls                      # 列当前目录
ls *.py                 # glob 展开：列出所有 .py
ls a.py b.py c.txt      # 多文件并列
ls sub1 sub2            # 多目录：每个前显 "dir:" 标题，空行分隔
ls -l a.py              # 单文件长格式
ls -la                  # 含隐藏文件
ls -lh                  # 人类可读大小（如 1.2K / 3.4M）
```

### 典型文件操作流程

```bash
mkdir -p project/src        # 创建嵌套目录
cd project                  # 进入
touch src/main.py           # 新建文件
echo "print('hi')" > src/main.py   # 写入内容
cat src/main.py             # 查看
cp -r src src_bak           # 备份
ls -l src src_bak           # 对比两个目录
```

## 3. Draco 函数（Python 实现）

复杂命令用 Python 标准库 / 第三方包实现，跨平台无系统依赖。调用形式：`函数名 位置参数 key=value ...`。

### 3.1 文件操作

#### ffind — 跨平台文件搜索（替代 find）

```bash
ffind "*.py"                       # 当前目录递归找 .py
ffind "*.py" path=src              # 在 src 目录找
ffind "*" dtype=dir                # 只找目录
ffind "test_*" path=tests dtype=file
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `pattern` | str | `*` | 文件名匹配模式（支持 `*` `?` `[]`） |
| `path` | str | `.` | 搜索根目录 |
| `dtype` | str | `all` | `all` / `file` / `dir` |

#### frename — 批量重命名（正则替换）

```bash
frename r"\.txt$" ".md"                  # 预览：txt→md（默认 dry_run）
frename r"\.txt$" ".md" dry_run=false    # 实际执行
frename r"img_(\d+)" r"photo_\1" path=imgs dry_run=false
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `pattern` | str | 必填 | 正则模式 |
| `replacement` | str | 必填 | 替换串（支持 `\1` 反向引用） |
| `path` | str | `.` | 目标目录 |
| `dry_run` | bool | `true` | 预演模式（只打印不执行） |

> 安全提示：`dry_run` 默认开启，确认预览无误后再设 `dry_run=false`。

#### ftree — 目录树

```bash
ftree path=.            # 当前目录树
ftree path=src          # 指定目录
```

### 3.2 归档操作

#### ftar — tar 打包 / 解压（替代 tar）

```bash
ftar out.tar "a.py b.py"              # 打包多文件（空格分隔，引号包裹）
ftar out.tar src                      # 打包目录
ftar out.tar.gz src gzip=true         # gzip 压缩
ftar out.tar extract=true             # 解压到当前目录
ftar out.tar.gz extract=true dest=./out   # 解压到 ./out
ftar out.tar extract=true verbose=true    # 解压并显示文件列表
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `archive` | str | 必填 | 归档文件路径 |
| `sources` | str | `""` | 源文件/目录（空格分隔）；`extract=true` 时忽略 |
| `extract` | bool | `false` | `true`=解压，`false`=打包 |
| `dest` | str | `.` | 解压目标目录（仅 `extract=true`） |
| `gzip` | bool | `false` | gzip 压缩（`.tar.gz` / `.tgz`） |
| `verbose` | bool | `false` | 详细输出 |
| `cwd` | str | `""` | 工作目录（覆盖 session cwd） |

#### fzip — zip 压缩 / 解压

```bash
fzip out.zip src              # 压缩
fzip out.zip "a.txt b.txt"    # 多文件
fzip out.zip extract=true     # 解压
fzip out.zip extract=true dest=./out
```

### 3.3 文本处理

#### fgrep — 文本搜索（替代 grep）

```bash
fgrep "TODO" path=src                         # 递归搜索 src
fgrep "TODO" path=src line_numbers=true       # 显示行号
fgrep "log" path=app.py ignore_case=true      # 忽略大小写
fgrep "^def " path=src regex=true             # 正则模式
fgrep "debug" path=src invert=true            # 反向匹配（不含 debug 的行）
fgrep "test" path=tests count=true            # 只输出匹配行数
echo "hello world" | fgrep world               # 从 stdin 搜索
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `pattern` | str | 必填 | 搜索模式（默认字面量；`regex=true` 时正则） |
| `path` | str | `""` | 文件/目录；空则从 stdin 读 |
| `ignore_case` | bool | `false` | 忽略大小写 |
| `regex` | bool | `false` | 正则模式 |
| `invert` | bool | `false` | 反向匹配 |
| `line_numbers` | bool | `false` | 输出行号 |
| `count` | bool | `false` | 只输出匹配数 |
| `max_count` | int | `0` | 最多输出 N 个匹配（0=不限） |

> 退出码对齐 GNU grep：`0`=有匹配，`1`=无匹配，`2`=错误。

#### fhash — 文件哈希

```bash
fhash file.txt                 # 默认 sha256
fhash file.txt algo=md5        # md5
fhash file.txt algo=sha1       # sha1
```

#### fjson — JSON 查询（替代 jq）

```bash
fjson data.json query=users.0.name        # 点路径取值
fjson data.json query=count               # 内置 count（数组长度）
echo '{"a":1}' | fjson query=a            # 从 stdin 查询
```

### 3.4 网络操作

#### pcheck — 端口检查（替代 telnet/nc）

```bash
pcheck example.com 80                    # 检查 80 端口
pcheck 192.168.1.1 port=22 timeout=5     # 自定义端口和超时
```

#### http — HTTP 请求（替代 curl）

```bash
http https://api.github.com                                          # GET
http https://httpbin.org/post method=POST body='{"k":"v"}'           # POST JSON
http https://api.example.com headers="Authorization:Bearer xxx"      # 带请求头
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `url` | str | 必填 | 请求 URL |
| `method` | str | `GET` | HTTP 方法 |
| `headers` | str | `""` | 请求头，格式 `Key:Value,Key2:Value2` |
| `body` | str | `""` | 请求体 |
| `timeout` | float | `30.0` | 超时秒数 |

#### dns — DNS 解析

```bash
dns host=example.com
```

## 4. 组合语义：管道 / 重定向 / 逻辑

自实现的组合语义引擎，**不依赖系统 shell**，跨平台一致。

### 4.1 管道 `|`

上游 stdout 作为下游 stdin（内存传递）：

```bash
echo hello world | wc              # 统计：1 行 2 词
echo piped | cat                   # 透传
cat a.py | fgrep def               # 搜索文件内容
echo '{"k":42}' | fjson query=k    # 管道查询 JSON
ls *.py | head -n 5                # 前 5 个结果
```

### 4.2 重定向

```bash
echo hello > out.txt               # 覆盖写入
echo more >> out.txt               # 追加
cat < input.txt                    # 从文件读 stdin
echo err 2> error.log              # stderr 重定向
```

### 4.3 逻辑操作符

```bash
echo first && echo second          # 上游成功才执行下游
false_cmd || echo fallback         # 上游失败才执行下游
echo a ; echo b                    # 顺序执行（无论成败）
mkdir dir && cd dir                # 组合：创建后进入
```

### 4.4 glob 展开

```bash
ls *.py                            # 展开为 ls a.py b.py ...
cat *.txt                          # 拼接所有 txt
rm *.tmp                           # 删除所有 tmp
```

无匹配时保留字面量（由命令自行报错），与 POSIX 行为一致。

## 7. AI 智能层

> 需配置 `DRACO_AI_API_KEY` 环境变量并 `/ai on` 启用。

```bash
/ai                    # 查看 AI 状态
/ai on                 # 启用
/ai off                # 禁用
/ai ask 如何批量重命名文件    # 向 AI 提问
/ai correct grpe test      # 让 AI 纠错拼错的命令（不执行）
/ai role                   # 列出命令角色卡
/ai role ls                # 查看某命令角色卡
/ai context                # 查看感知上下文
/ai emotion                # 查看当前情感状态
```

- **自动纠错**：命令失败后自动给出建议命令，确认即可执行（仍走风控）。
- **感知引擎**：记录常用命令、常见错误，主动给出 💡 建议。
- **AI 风控**：对模糊危险命令给出额外提示。

## 8. Agent 自动化

> Agent 通道默认注册内置 Draco 函数；用户自定义函数需 `agent_enabled` 并放在 `functions.py`。

```bash
/agent                 # 查看状态
/agent on              # 启用（加载用户函数）
/agent off             # 禁用
/agent list            # 列出已注册函数
/agent show ffind      # 查看函数源码
/agent reload          # 重新加载 functions.py
/agent templates       # 列出可用模板
/agent apply <模板名>   # 应用模板到 functions.py
/agent gen 批量下载图片并重命名   # AI 生成函数（代码即行动）
/agent run ffind "*.py" path=src # 显式调用函数
```

### 直接调用 Draco 函数

启用 Agent 后，Draco 函数可直接当命令用：

```bash
ffind "*.py" path=src
ftar out.tar "a.py b.py"
fgrep "TODO" path=src
```

### 用户自定义函数

在 `~/.opendracocli/functions.py`（或配置指定路径）中定义，函数第一个参数固定为 `ctx`：

```python
def my_task(ctx, name: str, count: int = 3) -> int:
    """我的任务示例"""
    for i in range(count):
        print(f"[{i+1}] hello {name}")
    return count
```

保存后 `/agent reload`，即可：

```bash
my_task world count=5
```

## 9. 安全与风控

### 四级风险评估

| 级别 | 说明 | 处理方式 |
|------|------|----------|
| safe | 读操作、ls 等 | 直接执行 |
| caution | 写操作、网络 | yes 确认 |
| danger | `rm -rf`、格式化 | yes 确认 + 警告 |
| critical | 系统级危险操作 | PBKDF2 身份验证 |

### 预评估命令风险（不执行）

```bash
/risk                    # 查看规则表
/risk test rm -rf /      # 模拟评估（绝不执行）
/risk test dd if=/dev/zero of=/dev/sda
```

### 路径白名单沙箱

写操作路径必须在白名单内，否则拦截。白名单由配置 `sandbox_writable_paths` 决定。

### 身份验证

```bash
opendracocli --setup-auth    # 设置密码（PBKDF2-HMAC-SHA256 存储）
```

critical 级操作需输入此密码确认。

## 11. 服务器 / 非交互部署

### 安装（无需 Rust 工具链）

```bash
# 开发机构建 wheel
maturin build --release
# 产出：target/wheels/opendracocli-0.1.0-cp310-abi3-manylinux_2_34_x86_64.whl

# 上传并安装
scp target/wheels/*.whl server:/tmp/
python3 -m venv /opt/odc.venv
/opt/odc.venv/bin/pip install /tmp/opendracocli-*.whl
```

abi3 wheel 兼容 Python ≥3.10，manylinux_2_34 兼容主流 Linux。

### 非交互执行

非 TTY 环境（管道 / 脚本 / MCP）自动降级到 `simple` 渲染器：

```bash
echo "ls -l" | opendracocli
```

### 作为 MCP 工具

将 `opendracocli` 作为命令执行通道接入 MCP server，每条命令走三层路由（Rust 内核 → Draco 函数 → exec 兜底），返回 stdout/stderr/exit_code。

## 12. 故障排查

| 现象 | 可能原因 / 解决 |
|------|-----------------|
| 启动报 `ModuleNotFoundError: opendracocli._native` | Rust 扩展未安装；用 `maturin develop --release` 或安装预编译 wheel |
| `ls *.py` 报 "没有那个文件" | 当前目录无 .py 文件，glob 无匹配保留字面量（正常行为） |
| 写文件被拦截 "沙箱限制" | 目标路径不在白名单；检查 `/risk` 或配置 `sandbox_writable_paths` |
| critical 操作要求密码 | 先 `opendracocli --setup-auth` 设置密码 |
| `/ai` 不可用 | 未设置 `DRACO_AI_API_KEY` 或 api_base 不可达；`/ai on` 查看详情 |
| `/agent gen` 失败 | 需先 `/ai on` 启用 AI（代码生成依赖 LLM） |
| Draco 函数直接输入不执行 | 未 `/agent on`；或首 token 未命中注册表（`/agent list` 查看） |
| Windows 上行为不一致 | 不会发生——所有命令走 Rust 内核 / Python 库，不依赖系统 shell |

### 查看帮助

```bash
/help              # 内置命令总览
/agent list        # 可用 Draco 函数
/risk              # 风险规则
/ai                # AI 状态
```

## 附：命令通道路由

```
用户输入
   │
   ▼
解析 → 组合语义引擎（|  > >> <  && || ;）
   │
   ▼
首 token 命中 Draco 函数？ ──是──▶ Python 通道（标准库/第三方包）
   │否
   ▼
Rust 内核命令？ ──是──▶ Rust 通道（PyO3，进程内零 IPC）
   │否
   ▼
exec 兜底（直接 exec 外部程序）
```

所有通道共用：风控评估 → 沙箱检查 → 执行 → 历史记录 → AI 感知。
